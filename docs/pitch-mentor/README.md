# OceanTwin SIH26067 — Six-Slide Winner-Mentor Guide

This directory converts a winner-heavy Smart India Hackathon presentation corpus into an actionable six-slide mentoring system for OceanTwin 3D.

## Read in this order

1. **00_CORPUS_METHOD_AND_LEARNING_RULES.md**  
   Evidence qualification, deduplication, winner weighting, scientific truth and forbidden claim transformations.

2. **01_SLIDE_1_TITLE_PAGE.md**  
   Product identity, official fields, one-line value proposition and cover hierarchy.

3. **02_SLIDE_2_IDEA_AND_PROPOSED_SOLUTION.md**  
   Problem truth, proposed solution, innovation and current proof.

4. **03_SLIDE_3_TECHNICAL_APPROACH.md**  
   Source-to-visual architecture, scientific methods, stack placement and verified comparison evidence.

5. **04_SLIDE_4_FEASIBILITY_AND_VIABILITY.md**  
   Technical/operational feasibility, risks, mitigation, fallback and deployment path.

6. **05_SLIDE_5_IMPACT_AND_BENEFITS.md**  
   Stakeholder workflows, before/after value, verified evidence and scale-up path.

7. **06_SLIDE_6_RESEARCH_AND_REFERENCES.md**  
   Authoritative sources, scientific methods, standards and reproducibility.

8. **07_MASTER_PROMPT_FAILSAFE_ROLLBACK.md**  
   Hierarchical execution protocol, validation gates, fail-safe modes and rollback policy.

## Core story the final six slides must preserve

**WHO / WHAT**  
OceanTwin 3D · SIH26067

↓

**WHY**  
Ocean data and observations are scientifically rich but fragmented across files, portals, depth, time and sensor workflows.

↓

**WHAT WE BUILT**  
One browser-native, scientifically traceable workspace integrating model fields and real observations.

↓

**HOW IT WORKS**  
Sources → adapters / QC → scientific services → API → 3D + analysis.

↓

**CAN IT WORK?**  
Verified vertical slice + explicit risks + fallbacks + operationalization path.

↓

**WHY IT MATTERS**  
Faster, clearer context integration for analysts, researchers, policy communication and education — without losing provenance.

↓

**WHY TRUST IT?**  
Authoritative data sources, explicit methods, verified metrics, standards awareness and honest limitations.

## Non-negotiable presentation principle

> **Do not make the judge derive the result from the slide. Show the takeaway first, then the evidence behind it.**

## Non-negotiable scientific principle

> **If the evidence is weaker than the desired sentence, weaken the sentence — never strengthen the evidence.**
