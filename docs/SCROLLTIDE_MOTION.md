# OceanTwin motion direction and resume contract

Scrolltide is a prompt/template library, not a runtime dependency. References reviewed: https://www.scrolltide.co/free, https://www.scrolltide.co/templates/glacier, https://www.scrolltide.co/faq. The public Glacier description informed deliberate pacing and a dominant scene. Its Get prompt link did not expose template source in the retrieved page. This implementation is original, inspired by public references; no paid template, marketing video or shader was copied. No purchase was made.

## Master prompt extension

Carry one motion language from startup to the final evidence and data sections. Preserve the existing real-readiness ocean loader and Earth-India-field camera journey. Make scientific source selection immediate. Reveal newly encountered content gently, give selected sources a persistent sea-glass marker, and bring the footer in as it enters view. Use the same easing and interaction feedback across routes. Keep all content visible without animation support. Observe newly mounted panels and route sections; disconnect observers on cleanup. Honor reduced motion, including changes while the app is open. Never capture wheel/touch events for decorative scroll effects: the scientific scene owns zoom and the document owns normal scrolling. Avoid decorative WebGL, large frame sequences and extra animation packages that compete with Cesium. Do not animate layout positions or transform scientific plots. Apply motion without changing data or delaying source readiness.
